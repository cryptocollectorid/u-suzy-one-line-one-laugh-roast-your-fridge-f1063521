Entry for the [make.fun bounty](https://make.fun/bounty/u-suzy-one-line-one-laugh-roast-your-fridge-f1063521): one line roasting my phone, written by `main.py` to `/output/entry.txt`.

> My phone dies at 23% like it's fainting for attention, and the charger only works if I hold it at a 45-degree angle and apologize first.

Run it with `python3 main.py`. The program validates the line against the sealed gate (1–200 characters, single non-blank line, valid UTF-8) before writing it.
